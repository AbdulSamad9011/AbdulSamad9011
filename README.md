## 🚀 Featured Projects

<details open>
<summary><b>🧬 Brain Tumor Diagnosis Assistant</b> — Faculty-supervised, in progress</summary>
<br/>

Multi-stage MRI/CT diagnostic pipeline built around a fan-out → fusion → synthesis pattern:

- Dual model heads — a **ResNet50/EfficientNet** classifier and a **MONAI 3D U-Net** segmenter — run in parallel on a preprocessed scan and merge through a fusion layer into a single structured finding
- Report-generation stage is a structured-output LLM call that only ever sees computed numbers (tumor type, confidence, mask volume, centroid) and **never raw pixels**, producing a clinician-reviewable `DiagnosticReport`
- Preprocessing: skull-stripping, normalization, resampling · **Grad-CAM** explainability on the classifier
- Serving surfaces: Streamlit UI, FastAPI endpoint, CLI
- Training on the public Kaggle Brain Tumor MRI and BraTS datasets

`Python` `PyTorch` `MONAI` `OpenCV` `FastAPI` `Streamlit` `Docker`

[![Repo](https://img.shields.io/badge/View_Repo-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/AbdulSamad9011/brain-tumor-diagnosis-assistant)

</details>

<details open>
<summary><b>🤖 Multi-Agent Research System</b> — Independent project</summary>
<br/>

A parallel multi-agent research pipeline built on **LangGraph**:

- A planner decomposes each query into 3–4 sub-topics and dynamically fans out specialist researcher agents via `Send()`, all running concurrently
- Each researcher gets dual-source retrieval — an internal RAG knowledge base and live **Tavily** web search — with every agent output enforced through typed **Pydantic** schemas rather than free text
- Shipped both a CLI and a Streamlit UI with live per-node progress, built on LangGraph's `StateGraph` with checkpointing

`Python` `LangChain` `LangGraph` `Pydantic` `Streamlit`

[![Repo](https://img.shields.io/badge/View_Repo-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/AbdulSamad9011/multi-agent-research-system)

</details>
